Curriculum Progression

The undergraduate program builds from foundational algorithmic thinking into deep operating systems, networks, and distributed applications.

Year 1 • Semesters 1 & 2

Programming & Mathematical Foundations

Semester 1:

  • Problem Solving in C (Pointers, Memory Allocation, Control Flow)
  • Engineering Mathematics I (Calculus & Linear Algebra)
  • Digital Logic & Basic Electronics

Semester 2:

  • Data Structures in C++ (Linked Lists, Stacks, Queues, Trees)
  • Object-Oriented Programming in Java (Classes, Inheritance, Polymorphism)
  • Discrete Mathematics (Set Theory, Combinatorics, Logic)

Key Competencies: Memory pointers, Big-O analysis, dynamic memory, and OOP encapsulation.

Year 2 • Semesters 3 & 4

Core Computer Systems & Software

Semester 3:

  • Design & Analysis of Algorithms (Greedy, Divide & Conquer, Dynamic Programming)
  • Database Management Systems (Relational Model, SQL, ACID Transactions)
  • Computer Architecture & Organization (Pipelining, Cache Memory)

Semester 4:

  • Operating Systems (Process Scheduling, Deadlocks, Virtual Memory Paging)
  • Computer Networks (OSI Model, TCP/IP, Sockets, HTTP/HTTPS)
  • Web Engineering (Semantic HTML5, Accessible CSS, REST APIs)

Key Competencies: Concurrency, process synchronization, schema design, and network protocols.

Years 3 & 4 • Semesters 5 through 8

Advanced Specializations & Capstone Engineering

Software Engineering & Distributed Systems

Design patterns, microservices, containerization (Docker), and cloud infrastructure.

Artificial Intelligence & Data Science

Supervised and unsupervised learning, neural networks, natural language processing.

Cybersecurity & Capstone Project

Applied cryptography, security audits, and full-semester group software capstone design.

Curated Free Learning Resources

High-value, verified free resources recommended for undergraduate computer science study:

Open Textbooks & Academic Courses

  • Harvard CS50x: Comprehensive introductory course covering C, Python, algorithms, and web fundamentals.
  • OSTEP (Operating Systems: Three Easy Pieces): Full free textbook on virtualization, concurrency, and persistence.
  • Open Data Structures: Free textbooks with implementations in C++, Java, and Python.

Coding Practice & Developer Tools

  • NeetCode Roadmap: Step-by-step problem sets organized by algorithmic topic.
  • MIT Missing Semester: Practical guide to Git, shell scripting, command line tools, and debugging.
  • MDN Web Docs: Authoritative reference for HTML5 semantics, CSS styling, and JavaScript standards.
